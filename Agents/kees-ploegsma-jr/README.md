## 💡 4. What we can learn (my analysis)
- The agent who gets you in is not always the agent who gets you up. A big sale needs someone the buying clubs already know.
- Honda changed representation at each stage: a Japanese agent to arrive, a Dutch agent for the sale, his own brother later. Yoshida's advice to choose an agent carefully fits this pattern.
